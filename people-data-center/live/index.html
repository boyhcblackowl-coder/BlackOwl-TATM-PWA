Alur Tindak Lanjut Kontrak

Proses standard yang dapat diterapkan di setiap outlet.

1. Verifikasi Dokumen

Cocokkan tanggal pada data center dengan PKWT terbaru dan EATS. Pastikan status karyawan aktif/resign sudah diverifikasi.

2. Tetapkan PIC dan Target

Catat siapa yang menindaklanjuti, target penyelesaian, serta langkah berikutnya. Sistem mencatat riwayat perubahan.

3. Review / Persetujuan

Jika perlu perpanjangan, lakukan koordinasi dengan atasan, ComBen, dan Legal sesuai ketentuan internal.

4. Selesaikan & Perbarui

Setelah ada bukti, tandai selesai dan isi tanggal akhir kontrak terverifikasi jika berubah. Penyimpanan memperbarui dashboard bersama.

DIPERIKSA SEBELUM DISIMPAN

Langkah Import Data Karyawan

1
Pilih file sesuai outlet / PT
Gunakan kolom EATS seperti Nama Karyawan, Nomor Induk Karyawan, Jenis Kelamin, Tgl Masuk, Lokasi Kerja, Posisi, Level.
2
Periksa data ganda
Sistem mendeteksi ID karyawan sama, nama + outlet serupa, dan kelengkapan field wajib.
3
Tambahkan baris baru
Baris duplikat atau konflik akan ditahan untuk ditinjau. Data lama tidak ditimpa.
4
Cocokkan dengan data HRIS / Payroll
Jika file memiliki kolom Status Karyawan, nilai Aktif/Resign/Tidak Aktif akan diikuti; jika tidak ada, roster dianggap Aktif. Cek identitas dan kontrak bila diperlukan.
Format tanggal: YYYY-MM-DD atau Excel date. Impor tidak mengambil alamat, agama, no. KTP, maupun data gaji.
