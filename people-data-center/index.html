KONFIGURASI AWAL · SATU KALI

Hubungkan Web App

Masukkan URL /exec dari Black Owl People Data Center yang sudah berjalan. PWA ini menyimpan alamatnya saja di perangkat Anda, bukan data karyawan, password, atau token.

INSTALL DI WINDOWS / ANDROID

Seperti TA & TM Workspace

Instal PWA ini melalui browser Chrome atau Edge. Aplikasi akan muncul dengan icon Black Owl dan dapat dipin ke desktop atau taskbar.

Jika tombol install belum tersedia, buka menu browser ⋮ → Install page as app atau Add to Home Screen di Android.

Dashboard PWA terintegrasi dapat dibuka langsung dari menu. Konfigurasi Google OAuth dan API dibutuhkan sebelum data live tersedia.
