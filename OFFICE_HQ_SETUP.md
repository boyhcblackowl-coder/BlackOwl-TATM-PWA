# Office HQ V3.1 — WebGL

Three.js r160 vendored from the official release (MIT, see vendor/THREE-LICENSE.txt). No external CDN or model downloads. The scene contains procedural stylized geometry, not custom GLB artist models or the original concept image. Real-time WebGL depth testing, shadow maps, tiled and wood textures, four named avatars with individual facial/hair geometry, seating, lighting, and existing navigation. Portraits are generated from the same models. Idle head animation is decorative, not employee attendance or AI work. No backend changes. AI remains disconnected. Browser GPU/hardware acceleration is required for the 3D scene; existing Workspace navigation remains available if unavailable.
